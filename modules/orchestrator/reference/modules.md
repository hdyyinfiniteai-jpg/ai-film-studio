# 五个内部模块 · 压缩规则

原五套 skill 在此降级为模块。只保留**编译期需要执行的规则**，
方法论全文见 `01_中文纯净版/`。

---

## M1 · 故事（SCREENWRITER）→ S1

**执行规则**
- 每场必有价值运动。`value_in == value_out` 的场次是**可以被剪掉的戏** ——
  G1 的 `polarity_not_flat` 会在呼吸场 >15% 时拦截。
- 价值对只能从 `config/value-taxonomy.json` 选。自由填会得到
  "有点紧张 → 更紧张" 这种废话，映射表也查不到。
- 中文语速常数（`config/zh-timing.json`）：正常对白 4.5 字/秒，古装 3.75，
  争吵 6.5，独白 2.5，短剧 5.5，喜剧 6.5 且**笑点后必留 0.8–1.5 秒**。
- 中文等宽排版约 1.2–1.4 页 ≈ 1 分钟。**页数只用于粗估，正式计算一律用秒。**

**三遍编译**（S1 只跑第三遍，前两遍是人的工作）
```
第一遍 结构遍：提骨架（场号/地点/在场/道具），全自动
第二遍 戏剧遍：判价值 + 焦点角色 + 转折类型 ← 唯一需要人的一遍，用二元问题问
第三遍 制片遍：计秒 + 可拍审计 + 情绪轨迹推导，全自动
```

## M2 · 表演（ACTING）→ S2 / S5

**双层档案**（原文 150–220 词主档案与长片管线冲突，此处拆开）
- `core_lock` 50–70 词：**每条提示词都带**
- `master_profile` 150–220 词：**仅首次出场与情绪转折带**

**声纹同源**：`voice_prompt`（怎么发声，逐字锁定不改）与
`voice_identity`（说什么：句长/语域/沉默模式/口头禅）必须来自同一次填写。

**编译期强制项**
- 微表演零情绪形容词 —— G5 的 `emotion_adjective` 是**红项**
- CU/ECU 必带眼神生命三件套：微跳视 / 眨眼质量 / 眼神光
- 多镜头必带 `However, when X` 条件式转变 —— 唯一能把表演从 3 分提到 5 分的机制
- 群戏反应必须错开，禁同步

## M3 · 资产（LIRA）→ S3

**三级路由，Vault 优先**
```
persona_vault_ref 存在 且 契约完整 → 直接引用，成本 = 0
persona_vault_ref 存在 但 缺状态变体 → 只生成缺失变体
不存在 → 转 persona-forge 定人，完成后入库
```

**模型路由（不让人选）**
| 类型 | 模型 | 关键约束 |
|---|---|---|
| 角色·定人 | soul-2.0 | 带 Soul ID |
| 角色·定妆 | soul-cinema | 16:9 |
| 场景 | soul-cinema | **禁写景深** —— 场景底图带浅景深会锁死后续所有广角镜头 |
| 道具 | nano-banana-pro | 反文字锚点「无可辨识文字」 |
| 局部改 | nano-banana-pro | CHANGE / PRESERVE EXACTLY 双段 |
| 救塑料感 | seedream-4.5 | 全画面纹理，中污染 |
| 最后5% | gpt-image-2 | 局部极强但全局变脏 |

**硬纪律：改动幅度 >40% 不要编辑，回生成端重出。**

图像提示词 80–150 词。**不要跨模态套用视频的长度** ——
图像模型单次前向，长度稀释注意力。

## M4 · 分镜（SHOTLIST-BUILDER）→ S4

**定量密度算法**（原文只有定性描述，此处定量化）
```
N₀ = ceil(T / 15)
+1  价值极性翻转（摄影机基调切换点）
+1  每个需独立成镜的插入镜头
+1  视角变化 >180°
+1  出现第 4 个有名角色
+1  服装/妆效状态变化
−1  尾段情绪连续可合并
−1  呼吸场
超 2500 字再拆
N_final = max(N, N₀)
```

**走位图是 G4 的硬要求**：2 人以上场次必须有批准的俯视图。
没有它，180 度轴线只能靠模型猜。

## M5 · 提示词（SEEDANCE）→ S5

**五段式**
```
【镜头】本条包含 N 个镜头，切换点严格发生在编号节拍处；除此之外不得有任何剪辑
【出场】@imageN = 完整句柄描述（头到脚，逐字复用资产层原文）
【焦距】只能取 lens_doctrine 的五个值之一
节拍N（Ts）：摄影机——<绑定编号的具体运动>。焦点角色处于「状态」的可观测状态
However, when <触发事件>，状态由 A 切换为 B
【微表演】只写可观测肌肉动作
【眼神】CU/ECU 必带三件套
【风格】光源 / 摄影机相对主光位置 / 色板 / 大气 / 调色参照
【禁止】去重后的完整禁令块
```

**中文字数上限是可配置参数，不是常数**：短剧 1800，长片放开至 2500。
原 skill 写死 1800 是短剧语境的产物。

**禁止写「逐渐」** —— 模型理解为全程均匀，情绪转折被抹平。
所有变化必须绑编号节拍。
