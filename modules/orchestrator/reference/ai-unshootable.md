# AI 不可拍清单

> 贴在编剧桌上。**从源头消灭必崩镜头，比在提示词层加十条防御句便宜得多。**
>
> 这份清单的每一条，都不是"AI 做得不好"，而是"AI 在当前架构下**结构性做不到**"。写进剧本 = 保证返工。

---

## 一、八条硬禁令（写进剧本就等于烧钱）

| # | 禁止写 | 为什么必崩 | 改写方案 |
|---|---|---|---|
| 1 | **镜面 / 玻璃 / 水面 / 抛光金属出现在画面** | 反射需要模型同时维护正向场景与反射场景两套一致性，当前无一模型能做到。反射里的人会是另一个人 | 换成门缝光影、投影在墙上的剪影、雨打在窗上但**不拍窗外倒影** |
| 2 | **角色出画后再入画** | 离框 = 隐含剪辑。再入画时模型按新角色处理，必然身份漂移 | 让角色**始终在画内**，或明确写成两条独立提示词（等于接受一次剪辑） |
| 3 | **画外状态变化**（换装、受伤、拿到东西） | 模型不记忆画外事件。上一镜没血的人下一镜有血 = 两个人 | 状态变化必须在画内发生，或在新提示词里**重新完整声明**该状态 |
| 4 | **单镜头内有名角色 > 3 人** | 句柄污染。第 4 个人开始，模型会把特征互相串 | 拆镜头，或让第 4 人以背影 / 局部 / 无名群众身份出现 |
| 5 | **生物力学描述**（"扭腰发力""重心下沉""借力翻身"） | 模型不理解力学链，会生成关节反向的畸形 | 只写**可观测结果**："他的肩先动，然后整个人向左倾" |
| 6 | **嗅觉 / 味觉 / 心理活动 / 记忆闪回内容** | 不可观测 = 不可拍 | 转成外部行为："他闻到了血腥味" → "他的鼻翼张开一次，随即屏住呼吸" |
| 7 | **连锁物理破坏**（多米诺、连环爆炸、坍塌波及） | 需要物理引擎级因果，模型只能生成"同时发生的混乱" | 拆成独立镜头，每镜只拍**一个**破坏事件的结果 |
| 8 | **超过 15 秒且不可剪的连续动作** | 超出模型时间窗，后段必然崩坏或循环 | 找一个自然剪辑点拆开；找不到就说明这个动作设计有问题 |

## 二、六条黄灯（可以写，但要付代价）

| 情形 | 代价 | 缓解 |
|---|---|---|
| 手部占画面 > 30% 且有动作 | 抽卡次数 ×1.4 | 严格点名手指数量与姿态，加禁令句 |
| 大幅摄影机运动 + 复杂前景 | 遮挡关系错乱 | 简化前景，或让摄影机运动幅度减半 |
| 快速动作（打斗、奔跑）超过 3 秒 | 动作糊、肢体穿模 | 拆成"起势 / 接触 / 结果"三镜 |
| 多角色同时反应 | 表情同步化（所有人同一表情同一时刻） | **强制错开**：写明谁先反应、隔多久第二人反应 |
| 极端景别（大远景带有名角色） | 尺度错配、面部糊 | 大远景不带有名角色，或接受面部不可辨 |
| 需要精确文字（招牌、书页、字条） | 文字必错 | 用**反文字锚点**：写明"无可辨识文字"，需要文字时后期贴 |

## 三、编剧自检问句（写完一场问三遍）

1. **这场戏里有任何东西会反光吗？**
2. **有没有哪个变化是发生在画面之外的？**
3. **我写的动作，摄影机看得见吗？还是只有角色自己知道？**

三个问题全过，这场戏才算 AI-ready。

## 四、给互动影游的补充三条

| 情形 | 问题 | 方案 |
|---|---|---|
| 分支汇合点的角色状态 | 玩家可能从多条路径抵达，服装/伤势状态不一致 | 在每个汇合点**强制状态归一**，或为每条路径备一套资产 |
| 玩家自定义外观 | 角色一致性契约失效 | 自定义项限制在**不影响 Soul ID 的维度**（配饰、颜色），不动骨相 |
| 同一场景多次重访 | 重生成会导致场景漂移 | 场景资产**一次生成、永久复用**，只重新生成角色层 |
