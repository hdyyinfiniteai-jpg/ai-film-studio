# 价值 → 情绪 → 摄影机 映射表

> 五份原始文档里一张都没有的表。它把麦基的「价值运动」、ACTING 的「情绪轨迹」、shotlist-builder 的「摄影机是焦点角色的情绪替身」焊成一条可执行链。
>
> **用法**：编剧在制片元数据里填了 `价值进入 → 离开`，摄影层查此表**自动**得到摄影机基调。人只在「这场戏要不要反着来」时介入。

## 二、三条使用纪律

### 纪律 1 · 摄影机运动必须绑编号节拍，不能均匀分布
❌ `摄影机手持，逐渐变得不稳定`
✅ `摄影机手持，起始时呼吸极微；节拍2处开始出现不规则横向漂移；节拍3处漂移幅度加倍并加入垂直方向抖动`

**理由**：Seedance / Kling 对"逐渐"的解读是全程均匀，会得到从第一帧就在抖的镜头，情绪转折被抹平。

### 纪律 2 · 每场只允许**一次**摄影机基调切换
一场戏里价值只翻一次（麦基），摄影机也只翻一次。若你写了两次切换，通常说明这场戏该拆成两场。

### 纪律 3 · 反用此表必须是有意识的决定，并写进决策日志
最强的镜头往往来自**反着来**：绝望的时刻用完全静止的广角、暴力用平稳长镜。但那是选择，不是遗忘。反用时在制片元数据里写一行 `映射覆写：<原本应为X> → <实际用Y> · 理由：<一句话>`。

## 三、与「呼吸场」的关系（易错点）

第 14 行的「平衡」不是漏填，是一种合法状态。但要注意 SCREENWRITER 的判定：

> **一场没有价值运动的戏，是可以被剪掉的戏。**

所以当你在制片元数据里发现 `价值进入 = 价值离开`，先问一句：**这场戏是必要的呼吸，还是应该删掉？**

- 必要的呼吸：它承担了信息投放、setup 埋线、或节奏调剂 → 保留，用静止摄影机
- 不必要：删掉，把它的信息塞进相邻场次的对白里

```
+ → −  ：手持渐乱 / 静止后推进 / 长焦压缩 / 低位下沉
− → +  ：乱渐稳 / 缓拉开 / 广角舒展 / 低位上抬
认知    ：冻结 0.5" 后极缓推进
死亡    ：顶拍 freeze 0.3–0.5"
无运动  ：这场戏可能该删
```
